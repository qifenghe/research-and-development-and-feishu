# 公司服务器部署配置

详细操作见[交接手册](../../docs/deployment/2026-10-19/龙汇研发管理系统_部署与维护交接手册.md)。

此处归档配置和脚本，不包含app.jar、构建后的html目录或images.tar。不能只克隆此目录便声称可离线启动；请使用完整交付包，或从配套源码构建并准备同版本产物。

当前修正版compose已包含Flyway基线0配置。现场旧包另用compose.override.yaml补充；维护时必须保留现场覆盖配置。

默认管理员口令只在服务器首次运行prepare-config.py时生成，不提交到Git。数据库与归档持久卷不可删除。脚本中的首次安装流程和备份恢复边界详见手册。
