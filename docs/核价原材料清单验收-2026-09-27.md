## 已验证

- 后端全套 383 项测试通过；前端 181 项测试通过，另新增真实 Vue 组件测试通过。最终复核结果在下文追加。

- 独立实例 8092 / 5193，新数据库迁移和默认权限初始化。
- 原辅料口径：处理后用量 100 kg、95% 利用率，领料 105.263157894737 kg；主料出成 89 kg，核价得率 84.55%。
- 处理前领料不会重复扣利用率；缺失/零/负/超范围利用率、来源篡改及版本冲突有校验。
- 可分装净重独立计算：89 kg、0.5 kg/袋、20袋/箱，178袋、9箱；余量保留。
- 草稿保存后恢复、修改使确认失效、未确认不能生成、归档后不能修改。
- 独立记录 `TASK-0003` / `PRICE-0001` 从打样、正式工艺、测试通过、核价保存、预览、确认、生成、审核到财务下载通过。

- `TASK-0004` / `PRICE-0002` 留作可编辑测试草稿。
- 单表导出、公式结果、100行物料、同料分行、长名称、非法表名字符、缺编码、包装内部代码及无旧产品残留有测试。
- `003` 是文本编码，`0.99` 是备注，不参与包装损耗推算。

## 复现

专用隔离实例运行后执行 `node scripts/verify-pricing-basis.mjs`。脚本固定访问 5193，每次新建带“核价验收”名称的独立记录，不删除已有数据。加 `--draft-only` 可留在草稿阶段。

测试入口：<http://127.0.0.1:5193/admin/pricing/PRICE-0002>。

## 限制

- 当前验证数据库为 H2，未用真实 PostgreSQL 实例验证迁移。
- POI 已求值，导出文件已做只读结构及数值检查。渲染工具对空共享字符串、尾部空格表名有显示兼容问题，不能替代原生 Excel 的打印和重算验收。
- 示例数据用于软件验收，不代表真实产品的工艺、食品安全或利用率标准。
- 未合并到原工作区，未推送 GitHub，原有未提交修改保留。
