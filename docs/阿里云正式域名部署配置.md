# 阿里云正式域名部署配置

## 域名

正式访问域名：

```text
https://rnd.longhuishiping.com
```

飞书后台配置：

```text
桌面端主页：
https://rnd.longhuishiping.com/admin/dashboard

移动端主页：
https://rnd.longhuishiping.com/m/login

H5 可信域名：
rnd.longhuishiping.com

重定向 URL：
https://rnd.longhuishiping.com/m/login
https://rnd.longhuishiping.com/m/login/callback
https://rnd.longhuishiping.com/admin/login/callback
```

保存后需要重新发布飞书应用。

## 证书文件

本机证书来源：

```text
/Users/lhrzp/Downloads/25733930_rnd/rnd.longhuishiping.com.pem
/Users/lhrzp/Downloads/25733930_rnd/rnd.longhuishiping.com.key
```

服务器建议存放路径：

```text
/etc/nginx/certs/rnd.longhuishiping.com.pem
/etc/nginx/certs/rnd.longhuishiping.com.key
```

示例上传命令，将 `your-ecs-ip` 换成 ECS 公网 IP：

```bash
scp /Users/lhrzp/Downloads/25733930_rnd/rnd.longhuishiping.com.pem root@your-ecs-ip:/etc/nginx/certs/
scp /Users/lhrzp/Downloads/25733930_rnd/rnd.longhuishiping.com.key root@your-ecs-ip:/etc/nginx/certs/
```

服务器上建议设置权限：

```bash
chmod 644 /etc/nginx/certs/rnd.longhuishiping.com.pem
chmod 600 /etc/nginx/certs/rnd.longhuishiping.com.key
```

## Nginx

项目内已配置：

```text
frontend/deploy/nginx.conf
```

该配置做了三件事：

```text
http://rnd.longhuishiping.com       -> 强制跳转 HTTPS
https://rnd.longhuishiping.com/api  -> 后端 127.0.0.1:8080
https://rnd.longhuishiping.com/admin -> PC 前端
https://rnd.longhuishiping.com/m     -> 手机端前端
```

部署到服务器后检查：

```bash
nginx -t
systemctl reload nginx
```

## 后端环境

本地联调环境文件已改为：

```text
FEISHU_MODE=OPENAPI
FEISHU_APP_URL=https://rnd.longhuishiping.com
```

服务器部署时也需要使用相同配置，并保留真实：

```text
FEISHU_APP_ID
FEISHU_APP_SECRET
FEISHU_CARD_ACTION_SECRET
```

不要把 `.env.feishu.local` 或证书私钥提交到 GitHub。
