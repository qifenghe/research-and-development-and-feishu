# 手机端研发核价闭环 UAT 验收清单

版本：v2.0
范围：纯网页账号 H5 模式；当前验收不依赖飞书。

## 本地入口

- PC 管理端：`http://<LocalHostName>.local:5173/admin/`
- 手机 H5：`http://<LocalHostName>.local:5174/m/login`
- 后端健康检查：`http://127.0.0.1:8080/actuator/health`

## 测试账号

统一测试密码：`123456`

| 角色 | 账号 | 主要入口 |
| --- | --- | --- |
| 研发内勤 | `rnd_assistant` | 录入需求、生成核价、通知财务 |
| 研发总监 | `rnd_director` | 审核需求、分配任务 |
| 研发人员 | `rnd_engineer` | 接受任务、填写实验单、通知测试 |
| 内部测试 | `tester` | 填写品尝测试、通过并锁版 |
| 财务 | `finance` | 查看、下载、确认接收核价文件 |

## 主流程

- [ ] 研发内勤登录后可进入“录入需求”。
- [ ] 产品名称、类型、客户、规格、应用场景、口味要求和申请人均可提交。
- [ ] 研发总监在“审核需求”看到新记录并审核通过。
- [ ] 审核后同一记录出现在“任务分发”，可指定研发人员和截止日期。
- [ ] 未单独指定产品负责人时，已分配研发人员自动作为产品负责人；产品负责人或研发总监可审核核价。
- [ ] 研发人员在待办看到任务，接受后进入实验单。
- [ ] 研发人员接受任务后直接进入实验单；可先编排本次工序，再开始现场填写。
- [ ] 配方填写原料、辅料或包材及重量；可选择多个主料，也可按全部非包材物料计算得率；利用率默认 100%。
- [ ] 至少填写一道工序的投入、下一步出成和余料，页面显示工序损耗。
- [ ] 填写成品重量与正整数袋数，页面显示核价数据预览和主料得率。
- [ ] 保存草稿成功后可通知内部测试。
- [ ] 测试人员填写复热方式、评分和口感评价，通过后版本锁定。
- [ ] 研发内勤直接看到“待生成核价”，无需先登记寄样。
- [ ] 生成核价 Excel 后状态为“待核价审核”；产品负责人或总监审核通过后才可通知财务。
- [ ] 财务仅看到已通知的核价文件，能够下载并确认接收。
- [ ] 确认接收后文件状态为“财务已接收”。

## 可选寄样支线

- [ ] 寄样登记和客户反馈可独立操作。
- [ ] 未寄样不会阻塞已锁定版本生成核价文件。

## 异常与重试

- [ ] 列表或详情接口失败时显示中文错误和“重新加载”。
- [ ] 重复点击财务“确认接收”不会产生重复接收记录。
- [ ] 审批前财务列表和详情不可见，通知财务返回“需要核价审核”。
- [ ] 核价退回必须填写原因；同一样品版本再次生成文件为 `A0-核价V2`，并重新进入待审核。
- [ ] 内部测试选择“复打样”后创建新样品版本和待接受研发任务（例如 `A0` 到 `A1`）。
- [ ] 已生成核价的版本不再出现在“待生成核价”。
- [ ] 提交后的实验版本只读，历史版本仍可查询。

## 自动化验收

在项目根目录运行：

```bash
node scripts/run-mobile-closed-loop.mjs
```

- [ ] 脚本检查后端、PC 和手机端服务可用。
- [ ] 五角色使用全新样品记录完成接力，并验证产品负责人审核和审批前财务不可见。
- [ ] 下载文件扩展名为 `.xlsx`。
- [ ] Playwright 报告 `1 passed`。
