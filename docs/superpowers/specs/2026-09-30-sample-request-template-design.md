# 样品需求按《产品需求填报表》调整

## 目标与范围

用户确认以《产品需求填报表(10).xlsx》的“产品需求填报表”工作表 A4:B19 为录入依据。改造现有样品需求流程，不导入模板中的示例为真实需求，不新建独立需求系统。

继续在隔离工作区开发，预览为 5193 / 8092。保留已导入的物料库及已有需求，不修改原 5183 环境。权限、审批顺序、任务分配、核价算法不改变。

## 页面及字段

电脑端采用四组卡片和双列布局，长文本占整行；移动端采用相同分组的单列布局。示例使用 placeholder，不作为默认值。

| 分区 | 字段 | 数据方式与规则 |
| --- | --- | --- |
| 基本信息 | 客户名称 | 沿用 customerName，必填 |
| 基本信息 | 产品名称 | 沿用 productName，必填 |
| 基本信息 | 是否提供标样 | 新增 referenceSampleProvided，可空布尔；新建时必须明确选是或否，不默认否 |
| 基本信息 | 产品规格 | 沿用 specification，必填；允许“500g/袋，10袋/件” |
| 产品要求 | 块型 | 新增 cutShape，必填文本，允许形态及长×宽×高与单位 |
| 产品要求 | 主要原料要求 | 新增 mainMaterialRequirement，必填文本；不是配方投料，不强制绑定物料库 |
| 产品要求 | 味型 | 沿用 flavorRequirement，必填，界面统一标为味型 |
| 产品要求 | 口感 | 新增 textureRequirement，必填文本 |
| 包装与使用 | 包装要求 | 新增 packagingRequirement，必填文本 |
| 包装与使用 | 储存方式 | 新增 storageRequirement，必填文本，提供冷冻、冷藏、常温提示但允许具体描述 |
| 包装与使用 | 应用场景 | 沿用 applicationScenario，必填 |
| 商务及补充 | 客户目标价格 | 新增 customerTargetPrice，必填文本，保留价格、计价单位、含税口径，不参与核价计算 |
| 商务及补充 | 需求量（每月） | 新增 monthlyDemand，必填文本，保留“袋/月、吨/月”等不同口径，不自动换算 |
| 商务及补充 | 其他特殊要求 | 新增 specialRequirements，必填文本，无则由用户填写“无” |
| 商务及补充 | 行情/参考价格 | 新增 referenceMarketPrice，选填文本 |
| 商务及补充 | 其他补充说明 | 新增 additionalNotes，选填文本 |

模板前 14 项必填，末两项选填。保留系统已有产品类型字段；申请人自动带出当前登录人，按既有后端身份规则提交，不增加可任意冒充的入口。

新文本字段长度上限统一 2000 字，前后空白去除；价格、需求量只记录原始需求，不猜测币种、税率、单位或换算关系。不增加标样附件上传功能，本轮只记录是否提供标样。

## 数据存储与兼容

新增字段分别持久化到 sample_request 的可空列。请求 DTO、领域模型、持久化映射、共享前端类型同步扩展，避免把全部内容拼进风味或备注字段。

新建需求由前后端同时校验所有必填字段，布尔值 false 是有效填写。选填空白规范为 null。已有需求的新字段保留 null，显示“未填写（历史需求）”，不以 false、“无”或示例补齐，不追溯阻止旧需求审批和任务流转。

研发任务详情通过原需求关联取得这些字段，不重复维护多份可编辑副本。审批结果、创建项目和任务的既有标识关联保持不变。内部创建需求的调用点和测试夹具随新契约同步调整；不保留无约束的旧新建接口绕过校验。

## 展示与权限

电脑、手机的录入、需求审核、需求详情、研发任务详情均显示对应内容。审核列表维持紧凑摘要，完整内容在详情或展开区展示，不把 16 项铺成横向大表。研发只读查看原始需求，审批人仍通过原审批动作操作。

保留现有读取、创建、审核及任务归属权限。沿用现有日志和错误反馈机制；接口返回具体缺失字段，不清空失败表单。后续编辑与版本化需求不在本轮新增。

## 验证与验收

1. 两端完整填写后保存成功，刷新后字段、换行、中文及“长×宽×高”原样可读。
2. 缺少任一必填项拒绝新建；“不提供标样”可以提交；选填项允许空白；空格不算填写。
3. 示例内容不进入数据库；价格和需求量不自动参与金额或得率计算。
4. 审核和研发任务详情可见完整需求，审批与任务创建流程仍能跑通。
5. 历史需求字段为空仍可查看、审核，不伪造为否或无。
6. 前后端测试、类型、契约、路由、构建通过；电脑及移动页面验证分组、标签与错误提示。
7. 只用新增且明确标识的验收需求测试，不覆盖用户原有需求和已导入物料。

## 不包含

不批量导入需求，不新增审批节点，不生成配方，不调整核价公式，不清理物料库或测试数据库，不推送 GitHub或合并分支。Excel 需求导出及标样附件可另行确认，不作为本轮默认功能。

## 自查

已核对模板全部 16 项、14 项必填和 2 项选填；字段均有存储及展示去向。旧数据保持可空与新建严格校验分开；不改变已批准的四组页面结构及现有业务权限。
