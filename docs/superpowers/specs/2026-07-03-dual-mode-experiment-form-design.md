# 双模式打样实验单设计

## 目标

减少研发人员现场录入量，同时保留新品打样对工序自由调整的能力。

## 两种模式

### 快速打样

- 直接使用系统推荐或历史工序。
- 进入逐工序执行页面。
- 每个工序默认只填写投入重量和产出重量。
- 损耗率由系统自动计算。

### 编排后打样

- 打样前进入工序编排。
- 支持新增、修改、复制、删除、上移和下移工序。
- 确认后进入与快速模式相同的逐工序执行页面。
- 保存草稿时按当前顺序写入 `processSteps.sequence`。

## 页面结构

1. 模式选择：快速打样、编排后打样。
2. 工序编排：仅编排模式出现。
3. 逐步打样：一次只显示当前工序。
4. 汇总提交：保存草稿、通知内部测试。

## 字段规则

- 自动带入：产品、版本、规格、研发人员、物料、工序名称。
- 必填：当前工序投入重量、产出重量。
- 选填：备注、照片、余料及异常说明。
- 自动计算：损耗重量、损耗率、工序顺序。

## 数据兼容

首版复用现有 `ExperimentProcessStep`，不新增数据库字段：

- `sequence`：工序编排顺序。
- `processName`：工序名称。
- `beforeWeightKg`：投入重量。
- `afterWeightKg`：产出重量。
- `lossRate`：自动计算。
- `remark`：控制要点或异常说明。

后续接入 ERP 后，物料和工序模板通过同步服务写入系统数据字典，本次不阻塞双模式页面上线。
