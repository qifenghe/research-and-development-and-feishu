# 配方、工序损耗与出成设计

## 目标

把打样实验单拆成三个清晰区域：配方、工序、最终出成。研发人员只填写现场真实数据，系统自动计算比例、损耗和出成率，并保持历史版本只读。

## 方案选择

### 方案 A：继续把新增数据写进备注

不改数据库，但余料、主原料和出成比例只能拼接进文本，无法可靠计算、检索和导出。不采用。

### 方案 B：扩展现有物料与工序模型（采用）

在现有 `ExperimentMaterial`、`ExperimentProcessStep` 上增加结构化字段。改动集中，能够兼容当前实验单、核价文件和历史版本。

### 方案 C：新建独立配方与工艺批次模型

长期扩展性最好，但首版改动面过大，超出当前研发试用范围。不采用。

## 配方区域

标题统一为“配方”。每行字段如下：

| 字段 | 规则 |
|---|---|
| 类别 | 下拉选择：原料、辅料、包材 |
| 主原料 | 单选；整份配方只能指定一项，包材不能设为主原料 |
| 物料名称 | 必填 |
| 配方比例 | `单项实际重量 / 配方投入总重量 × 100%`，自动展示 |
| 实际重量 | 必填，统一折算为 kg 保存 |
| 单位 | g、kg |
| 利用率 | 默认 100%，允许修改 |
| 备注 | 可选 |

保留物料编码作为后台兼容字段，但首版页面隐藏，后续 ERP 数据字典匹配后自动带入。

## 工序区域

工序使用选项卡展示，每个选项卡代表一个工序。支持新增、重命名、复制、删除和调整顺序。

每个工序填写：

- 投入重量：第一道工序默认取主原料实际投入重量。
- 下一步出成重量：当前工序产生的可用物料重量。
- 余料重量：未进入下一步但需要记录的物料重量。
- 余料去向：可继续使用、退料、废弃。
- 损耗重量：`投入重量 - 下一步出成重量 - 余料重量`，系统计算，不允许小于 0。
- 损耗率：`损耗重量 / 投入重量 × 100%`，系统计算。
- 备注：记录工艺参数或现场异常。

上一工序的“下一步出成重量”自动带入下一工序的“投入重量”，研发人员可以确认或调整。修改上一步数据时，未人工修改的下一步投入同步更新；已人工修改的值保留并给出差异提示。

## 最终出成

- 成品实际产出重量：研发人员填写。
- 主原料实际投入重量：从唯一主原料自动读取，只读展示。
- 成品出成比例：`成品实际产出重量 / 主原料实际投入重量 × 100%`。
- 单位：与主原料统一折算后计算。
- 备注：可选。

未指定主原料时可以保存草稿，但不能提交内部测试；系统提示“请先指定主原料”。主原料投入为 0 时不计算比例。

## 数据模型

`experiment_material` 增加：

- `material_category`：RAW、AUXILIARY、PACKAGING。
- `is_primary_material`：是否主原料。
- `formula_ratio`：配方比例快照。
- `input_unit`：录入单位。

现有 `stage` 字段迁移为类别兼容来源；现有数据按“原料/辅料/包材”映射，新数据同时写入结构化类别。

`experiment_process_step` 增加：

- `remaining_weight_kg`：余料重量。
- `remaining_disposition`：REUSE、RETURN、DISCARD。
- `loss_weight_kg`：损耗重量快照。

`experiment_form` 增加：

- `finished_output_weight_kg`：成品实际产出重量。
- `finished_yield_ratio`：最终出成比例快照。

所有计算值在保存时由后端重新校验，不能只信任前端结果。

## 兼容与版本

- 老实验单缺少新字段时按原字段展示，利用率缺失按 100% 处理。
- 已提交或锁定版本保持只读，不回写历史数据。
- Excel 实验单增加主原料标记、配方比例、余料、损耗重量和最终出成比例。
- 核价文件继续读取物料实际重量和利用率，不因页面改版中断。

## 验证

- 配方只能存在一个主原料。
- 新增物料利用率默认为 100%。
- 工序出成能正确带入下一工序投入。
- 投入、出成、余料能够正确计算损耗重量和损耗率。
- 最终出成比例严格以主原料实际投入重量为分母。
- 草稿保存、重新打开、版本锁定和 Excel 导出字段一致。
