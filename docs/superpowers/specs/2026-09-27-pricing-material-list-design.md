## 页面

在核价生成流程中提供“核价数据确认”，四区：

1. 文件信息：自动带出名称、类别、规格、负责人、编写人、版本、日期；文件编号和企业信息来自配置或授权录入。实际批准信息取审批记录，未批准不伪造受控/批准状态。
2. 原辅料清单：按大工序分组、步骤顺序排列外部投料，不合并跨工序同物料。显示编码、名称、配方用量 kg、参考利用率 %、参考领料 kg。展开显示来源步骤、重量口径、取数依据、备注和确认状态。
3. 出成与包装：主料出成、可分装成品净重、单包净重、每箱包数分别确认；包装表显示参考数量及单位、规格、内部代码、备注。参考数量与实测数量明确区分。
4. 保存草稿、预览原材料清单、确认生成。缺项可保存、预览带缺项和非正式标识；生成前弹窗确认并由服务端校验。

小步骤中只提供折叠的“核价领料信息”入口或来源提示；核价确认快照为核价计算的唯一依据，不能同时维护两套互相覆盖的可编辑值。新录入的参考信息不反写实际投料及工序计算。

## 取数与计算

每笔外部投料保留来源版本、工序/步骤/物料标识、原始重量及取数方式。中间产物仅作为处理后用量的关联依据，不再形成仓库领料行。

### 两种重量口径

- 处理后用量：研发确认配方用量 U 和参考利用率 r，参考领料 Q = U / r。
- 处理前投入：原始投入为领料基准 Q；研发关联可归属于此物料的处理后用量 U，参考利用率 r = U / Q。不得再对 Q 除以 r。混合后产出不能直接视作单种原料净用量；无可靠来源时保持待确认，可填写人工确认值与依据并保留原始记录。

利用率不静默默认 100%；界面百分数与后端比例单位统一换算。参考利用率要求 0 < r <= 1；吸水增重属于工艺得率，不能冒充原料利用率。零用量可表达但不进行 0/0 推导；负数、非法数值和零领料分母阻止生成。计算使用十进制定点，中间不按显示精度截断，导出显示精度与计算精度分离。

### 得率

- 工艺主料得率沿用现有口径，不受核价确认影响。
- 核价主料得率 = 确认的最终主料出成 / 对应主料参考领料总量。
- 主料多行时必须明确哪些行属于同一最终主料范围，不能把混合成品重量或无关主料自动纳入。分子、分母和来源在确认页面可追溯；无法确定则缺项，不猜测。
- 参考案例：用量 100kg、利用率 95%，领料 105.263157…kg；主料出成 89kg，核价得率 84.55%。已记录 105.263157…kg 处理前投入时不得再次扣 5%。

### 包装

可分装成品净重独立确认，不从主料得率推断。参考完整包数按成品净重/单包净重向下取整，并展示余量；每箱包数为正整数，参考箱数按包数/每箱包数向上取整，标注不足整箱。实测包数单独保留。袋、标签、箱等仅在明确对应关系后给建议数量，胶带等不得套用袋数。允许授权人员调整并记录原因。

模板备注中的 0.99 等含义未确认，原样作为备注，不参加计算，不命名为损耗率。这里的取整为拟定默认规则，用户审阅本设计时可修改。

新核价文件生成后快照和文件绑定，失败保留草稿且不得标记生成成功。历史已生成文件继续下载原字节；新格式通过新版本生成，不回写旧文件。旧版来源可预填利用率，但须确认其口径后使用。
