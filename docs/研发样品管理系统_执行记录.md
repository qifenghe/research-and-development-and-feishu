## 2026-06-18 第二轮执行

已完成主业务链路的内存版后端 API：

- 新增 SampleRequest、SampleProject、SampleVersion、RndTask、RndTaskStatus 等主链模型。
- 新增 SampleWorkflowService，支持研发内勤创建需求、研发总监审核通过、自动生成样品项目、自动生成 A0 样品版本、自动生成任务池任务。
- 新增 SampleWorkflowController，提供首批 REST API。

已实现接口：

- POST /api/v1/sample-requests：创建样品需求单。
- GET /api/v1/sample-requests：查看样品需求列表。
- POST /api/v1/sample-requests/{id}/approve：研发总监审核通过需求，生成项目、A0 版本和任务池任务。
- GET /api/v1/rnd-tasks/pool：查看研发任务池。
- POST /api/v1/rnd-tasks/{id}/assign：研发总监分发任务给具体研发人员。

已补充测试：

- SampleWorkflowControllerTest：覆盖创建需求、审核生成项目和 A0 版本、任务池查询、任务分发。
- 覆盖异常场景：审核不存在需求、分发不存在任务时返回业务错误码。

验证结果：

- mvn test：12 tests, 0 failures, 0 errors。
- node prototype-app/test-prototype.mjs：30 views, 29 navigation targets, 5 top-level modules。

当前实现说明：

- 当前主链服务使用内存存储，目的是先跑通业务接口和状态语义。
- 下一步建议接 PostgreSQL/JPA 或 Flyway，把 SampleRequest、SampleProject、SampleVersion、RndTask 落成数据库表。
- 也可以先继续向后实现研发人员接受任务、实验单草稿、提交内部测试这段流程。
