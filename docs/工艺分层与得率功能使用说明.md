# 研发打样工艺、配方与得率使用说明

本功能用一份打样工艺同时管理大工序、小步骤、步骤投料、中间产物、得率和关键控制点。工艺正式提交后，同一个正式版本可生成标准配方和研发版 SOP，并为后续生产核价提供工艺和得率依据。

## 从哪里进入

PC 端进入“我的打样任务 → 打样实验单”后，直接进入“工艺工作台”，页面默认显示“大工序编排”。先完成大工序路线，再点击某个大工序的“进入步骤”维护它的小步骤。

- 研发总监可编辑和提交工艺。
- 研发人员只能编辑、提交本人负责任务的工艺，也只能生成该任务的成果文件。
- 测试人员只读查看已正式提交的工艺版本，并只看到已成功生成的配方和 SOP，不能看草稿、不能编辑或生成文件。

## 打样编排顺序

### 1. 先编排大工序

工艺工作台打开后直接显示“大工序编排”，可以拖入模板、新建、复制、删除和调整顺序。同一模板可重复使用。建议先完成整条大工序路线，例如“解冻 → 修割 → 腌制 → 熟制 → 冷却”，再点击大工序进入其小步骤。

大工序卡片会显示小步骤数量和当前得率。不需要计算得率的管理性或检查性工序，可设为“不计算得率”。

### 2. 再进入大工序编排小步骤

小步骤可从模板重复拖入，也可新建、复制、删除和调整顺序。每个小步骤重点维护：

- 步骤名称、类型、设备、操作要求；
- 两组快捷参数，参数名、值和单位均可自定义，例如温度、时间、真空度或浓度；
- 本步骤投料；
- 产出、中间状态及是否继续流转；
- 关键控制点及实测记录。

### 3. 在每个小步骤中加料

投料分为两种来源：

- **外部物料**：从仓储、采购或配方物料库进入，可选主料、辅料或加工用水，并填写物料编码、名称和重量。所有外部投料会汇总到最终配方，同一物料在多个步骤加入时会合并重量，同时保留加入步骤明细。
- **前序中间产物**：只能从前面步骤已标记“继续流转”的产出中选择。它只记录主料的名称、状态和重量变化，不创建物料编码、不进入物料库，也不重复计入配方。

每个小步骤最多只能指定一个用于得率的主料投入和一个主料产出。辅料和加工用水参与配方和物料平衡，但不改变主料得率的分母。

### 4. 记录产出和关键控制点

产出可记录为中间产物、成品、合格产出、余料、尾料、取样或废弃物。如果后续步骤还要使用，勾选“继续流转”。删除或移动已被后续步骤引用的产出时，系统会先列出受影响的投料并要求确认修复。

关键控制点可分为食品安全关键点、研发品质关键点和普通工艺参数，并设置“极重要、重要、一般”。可记录目标值、上下限、检测方法和工具、频次、实测值、偏差处理、复测结果和确认人。

极重要项目没有实测值或确认人，或超限后偏差处理与复测未闭环时，仍可保存草稿，但不能正式提交。全部实测判定合格后可点击“本人确认”，保存时由服务器记录真实登录人和时间；未改变控制标准和实测记录的再次保存保留确认，修改后需要重新确认。发生偏差时仍须研发总监完成偏差确认。

## 得率怎么计算

系统展示小步骤、大工序和成品三层得率，正式提交时以后台重新计算的结果为准。

`小步骤主料得率 = 本步骤主料产出重量 ÷ 本步骤主料投入重量 × 100%`

`大工序得率 = 本大工序末端主料产出重量 ÷ 本大工序首端主料投入重量 × 100%`

`成品得率 = 100 × (大工序1得率 ÷ 100) × (大工序2得率 ÷ 100) × ……`

例如：解冻 90% × 修割 80% × 熟制 70% = 成品得率 50.4%。

小步骤得率只用于查找异常，不再参与成品得率连乘，避免重复计算。设为“不计算得率”的大工序不参与连乘。需要计算得率但缺少首端主料投入或末端主料产出时，系统会阻止正式提交。

大工序之间必须承接同一条连续主料链，承接重量必须与前序产出一致。取样、废弃等应在前序步骤单独记录，从可流转产出中扣除。独立主料路线、分叉、跳链或重量不一致时，不展示成品连乘得率，并阻止正式提交；本版不支持多条独立主料路线汇合后的成品得率。不计算得率的检查性工序不得改变主料重量。

物料平衡另行计算：`平衡差 = 全部投入 − 全部分类产出`。平衡差超过设定允许范围时，需在大工序备注中填写差异说明才能提交。

大工序“全部投入”包含外部物料和其他大工序转入的中间产物，只排除本大工序内部重复流转。例：上道转入90 kg、末端产出72 kg，主料得率80%，平衡差18 kg；这90 kg中间产物仍不会重复进入最终配方。

## 同工序得率对比

研发人员或总监在工艺工作台点击“同工序得率对比”，已完成、锁定的样品也能查看。选择工序分组和基准样品后，表格展示产品、打样单、正式版本、主料投入、主料产出、得率及相对基准的百分点差异。

只使用可访问打样单的最新正式版本，最多200份；总监可跨产品查看，研发人员仍限于自己有权访问的任务。按工序编码、得率口径、主料标识和投入/产出状态分组，不按同名工序直接合并。缺少编码、缺少主料数据或存在无效主料链的历史记录不参与比较。偏差用于研发排查，不作为自动判废依据。

## 草稿、正式版本和修订

- 打样阶段会自动保存，也可点击“保存草稿”。网络异常时，页面会保留本地草稿并显示失败提示。
- 草稿可反复修改，但不生成正式配方、SOP 或核价文件。
- 点击“正式提交”后，先查看配方摘要、各大工序得率、成品得率和待处理项，勾选确认后才能生成不可直接覆盖的正式版本。
- 要修改正式版本时，在“版本历史”中打开目标版本，点击“从该版本新建草稿”。必须填写变更原因并明确确认；再次正式提交前，还要核对与来源版本的新增、删除和修改差异。
- 旧正式版本及其成果文件始终保留，不会被新版本覆盖。

## 配方、SOP 和核价什么时候生成

### 标准配方 Formula XLSX

工艺正式提交后，在“成果输出中心”选择对应正式版本并生成。文件汇总外部主料、辅料和加工用水，包含打样重量、配方占比、100 kg 折算量和加入步骤。中间产物不会生成配方行。

### 研发版 SOP DOCX

与标准配方一样，只能从正式工艺版本生成。SOP 包含大工序和小步骤顺序、步骤投料、设备与操作参数、中间产物流转、得率、关键控制标准、偏差处理及测量追溯附录。

配方和 SOP 生成失败时会显示原因，可在同一正式版本下重新生成；生成失败不会取消已提交的正式工艺版本。

### 生产核价

核价仍按现有业务流程办理，不会在工艺草稿或正式提交时提前生成。包装清单确认并生成可下载的正式核价文件时，服务端自动取该打样单当时最新的正式工艺版本，并将它固定绑定到核价记录。该时点之后即使又提交了新工艺版本，也不会改变已生成核价文件的来源版本。这一流程不需要、也不提供手工选择工艺版本的入口。

## 手机端怎么看

手机端进入同一打样实验单。研发人员在打样阶段仍以 PC 端维护分层工艺为准；测试人员在手机端只读查看最新正式版本。可展开大工序查看小步骤、参数、设备与操作要求、主辅料、中间流转、关键控制点、大工序得率和成品得率；已就绪的标准配方和 SOP 可直接下载。

## 常见阻断提示

| 页面提示 | 处理方法 |
| --- | --- |
| 至少需要一个大工序 | 先从模板拖入或新建大工序。 |
| 需计算得率的大工序缺少主料投入或主料产出 | 在该大工序的首端步骤补主料投入，在末端步骤补主料产出；确实无需计算时改为“不计算得率”。 |
| 主料中间产物流转存在断链或循环 | 重新选择一个真实存在且位于当前步骤之前的“继续流转”产出。 |
| 配方缺少外部主料，或外部物料总重量为 0 | 至少在一个小步骤加入重量大于 0 的外部主料。 |
| 极重要关键控制点未完成 | 补实测值和确认人；如有超限，完成偏差处理、复测并标记已闭环。 |
| 物料平衡差超过允许范围 | 核对所有投入、产出、余料、尾料、取样和废弃重量，并在大工序备注填写差异说明。 |
| 工艺方案已被更新 | 说明有其他人或另一页面已先保存；刷新后比较差异，不要直接覆盖。 |
| 从正式版本新建草稿缺少变更原因 | 填写真实修改原因并勾选确认，再新建草稿。 |
| 当前没有正式工艺版本 | 先由有权限的研发人员完成草稿校验并正式提交。 |
| 成果文件尚未生成或生成失败 | 由研发总监或任务负责人在该正式版本下生成或重试；测试人员只能下载“已就绪”文件。 |

## 历史数据

旧实验单仍可读取，历史平铺工序会以简化大工序显示；如果原数据没有小步骤、中间产物或关键控制点，系统不会自动猜测补全。旧数据在保存前不会被改写，现有实验单和核价流程继续保持兼容。
